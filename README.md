# RapidSim-prompt-charmonia

Code used to generate D0 anti-D0 decays coming from prompt psi(3770) and chi_c1(3872) states in RapidSim, from 14 TeV pp collisions.

I used RapidSim v1.4.0 to generate these decays. However I changed src/RapidParticleData.cc and src/RapidParticleData.h to allow for a Uniform (UNI) D0 anti-D0 distribution to be produced, and I changed config/particles.dat to setup the X(3872) and psi(3770) and UNI particle parameters. I also added a ROOT file with a new pT and pseudorapidity histogram for prompt charmonia. For near-threshold charmonia the decay dictates, that in the measurement frame, the particles in the D0 anti-D0 system will move approximately colinearly; thus the new ROOT file was generated using doubler.C which took the included FONLL charmed meson transverse momentum and pseudorapidity distributions, and simply extended them to represent low-mass charmonium by simply doubling the transverse momenta generated, while maintaining the pseudorapidity (LHCbx14.root). These changed and new files have been uploaded to this git repository (in the RapidSim directory), and are needed to generate RapidSim MC using the decay and config files provided in the psi*, X*, and DDbBackground directories.
